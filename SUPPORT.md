# Support

For installation help, bug reports, or feature requests, open a GitHub issue at:

<https://github.com/rubenviolinha/trading212-mcp/issues>

Do not include Trading 212 API keys, secrets, account numbers, screenshots containing sensitive information, or complete portfolio exports in an issue.

For a future hosted service, this page must be updated with a monitored private contact route for account deletion, privacy requests, and security reports before public launch.
